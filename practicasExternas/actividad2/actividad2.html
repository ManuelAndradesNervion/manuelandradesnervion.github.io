Etiqueta vacía
etiqueta HTML que no contiene contenido ni necesita una etiqueta de cierre.
Atributo global
atributo que proporciona información adicional a un elemento HTML y cuyo valor se establece directamente en la propia etiqueta.
Marcador local
referencia que permite enlazar con una parte específica de una misma página HTML, normalmente mediante el atributo id de un elemento.
