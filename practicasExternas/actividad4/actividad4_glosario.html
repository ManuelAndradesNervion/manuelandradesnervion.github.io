br

Introduce un salto de línea dentro de un texto.


hr

Inserta una línea horizontal que representa un cambio de tema o separación entre contenidos.


img

Inserta una imagen en la página web.


meta

Proporciona información sobre el documento HTML, como la codificación de caracteres o la descripción de la página.


link

Establece una relación entre el documento HTML y un recurso externo, como una hoja de estilos CSS.


input

Permite introducir datos mediante un campo de formulario, como texto, contraseñas o casillas de selección.


area

Define una zona interactiva dentro de un mapa de imagen.
